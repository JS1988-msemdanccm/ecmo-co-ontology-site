Clinical Scenario

Central V-A ECMO — Failure to Wean from Cardiopulmonary Bypass

Adult patient unable to be weaned from cardiopulmonary bypass at the conclusion of cardiac surgery. Central (transthoracic) V-A ECMO is established directly on the cardiac surgical field:

  • Drainage: right atrium (RA), 32 Fr large-bore cannula — directly via open sternotomy
  • Return: ascending aorta, 22 Fr — direct aortic cannulation
  • Sternum is left open (open chest); cannulae exit through skin at sternotomy edges and are removed at chest closure
  • Anticoagulation managed with heparin; flows typically 4–6 L/min

Central cannulation provides superior hemodynamic support but carries higher risk of infection and bleeding compared to peripheral. This scenario asserts the same ecmo-co:VA-mode as the peripheral V-A scenario; what differs is the cannulae, whose anatomy this scenario records in their labels.

Key ECMO-CO Features in This Scenario
Cannula anatomy recorded in labels only — the scenario asserts no anatomical site for either cannula; "Right atrial drainage cannula" and "Ascending aortic return cannula" are rdfs:label text. The TBox defines ecmo-co:CentralCardiacStructure, but this scenario does not use it, and that class has no FMA mapping. Q1 below therefore matches label text.
Transthoracic placement note on the epoch record — the CannulationConfiguration rdfs:comment reads "Sternotomy left open; cannulae exit through skin and are removed at chest closure." It is free text, not a coded field.
Same VA-mode, different cannulae — the ELSO Registry records a Site code for each cannula (for example RA and Aorta here, against RFV and RFA for femoral cannulation), so its records distinguish central from peripheral V-A. In this scenario ECMO-CO records the same distinction only in cannula labels.
Two-cannula circuit — the circuit aggregate (bfo:0000178) has two Cannula members plus a pump and an oxygenator; each cannula's LumenConduit bears a Function and a Role. The scenario asserts membership only, with no Ports or CircuitConnection records.

SPARQL Competency Queries

Q1 — Find V-A runs whose drainage cannula is labelled atrial

# Namespace declarations omitted.
SELECT ?run ?cannula ?label
WHERE {
  ?cfg  ecmo-co:hasModeAssertion  ecmo-co:VA-mode ;
        ecmo-co:isAbout           ?cannula .
  ?run  ecmo-co:hadConfigurationEpoch  ?cfg .
  ?lc   bfo:0000176  ?cannula ;
        ecmo-co:bears    ?fn .
  ?fn   rdf:type  ecmo-co:DrainageFunction .
  ?cannula  rdfs:label  ?label .
  FILTER(CONTAINS(?label, "atrial"))
}
ORDER BY ?run
?run | ?cannula | ?label ---------------|------------------|------------------------------------------------------- :ECMORun_VAC01 | :Cannula_RA_32Fr | "Right atrial drainage cannula, 32 Fr (transthoracic)"

The FILTER matches label text because this scenario records cannula anatomy only in labels.

Q2 — Retrieve epoch metadata including comment

# Namespace declarations omitted.
SELECT ?cfg ?mode ?start ?comment
WHERE {
  ?cfg  rdf:type              ecmo-co:CannulationConfiguration ;
        ecmo-co:hasModeAssertion  ?mode ;
        ecmo-co:startedAt         ?start ;
        rdfs:comment          ?comment .
}
ORDER BY ?cfg
?cfg | ?mode | ?start | ?comment ---------------------|-----------------|------------------------|------------------------------------------------------------------------------------- :Config_VAC01_Epoch1 | ecmo-co:VA-mode | "2026-05-11T11:20:00Z" | "Sternotomy left open; cannulae exit through skin and are removed at chest closure."
