About these examples

The five scenarios below are a subset of the 17 ABox scenario files (16 clinical scenarios + 1 negative fixture) in the ECMO-CO test harness, chosen to span the modelling range. Each is a synthetic Phase 1 ABox instance showing how ECMO-CO encodes an ECMO configuration. The pages show illustrative excerpts of the scenario files at the commit named in the page footer. Click any card to view the RDF excerpt and circuit diagram.

Canonical two-site veno-venous support. Femoral vein drainage (25 Fr) → pump → oxygenator → IJ return (21 Fr). Full 5-connection port-to-port topology encoded.
