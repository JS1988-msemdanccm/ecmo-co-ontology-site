Clinical Scenario

V-A ECMO — Cardiogenic Shock, Peripheral Femoral Cannulation + Distal Limb Perfusion

Adult patient presenting with refractory cardiogenic shock requiring emergent peripheral V-A ECMO. Three-cannula configuration:

  • Drainage: right common femoral vein, 25 Fr — deoxygenated venous blood
  • Return: left common femoral artery, 17 Fr — oxygenated blood returned retrograde
  • Distal perfusion catheter: 8 Fr anterograde into left superficial femoral artery — prevents ischaemia distal to the arterial cannula; branches off return limb via Y-connector

Distal limb perfusion is standard of care with femoral arterial cannulation. The scenario includes the catheter as a real component of the configuration even though it is not a drainage/return path of the main circuit.

Key ECMO-CO Features in This Scenario
Three-cannula circuit aggregate — ecmo-co:ECMOCircuit has three ecmo-co:Cannula members via bfo:0000178: FemV (drainage), FemA (return), DistalPerfCath (distal perfusion). The aggregate also lists the pump, the oxygenator and three tubing segments.
ReturnRole without ReturnFunction on the distal perfusion catheter — the catheter's LumenConduit bears a ReturnRole but no ReturnFunction. ECMO-CO keeps design intent (Function) apart from configured use (Role); this scenario asserts the role and no function for the catheter.
VA-mode CannulationConfiguration GDC — ecmo-co:VA-mode asserted; the distal perfusion catheter is included in ecmo-co:isAbout, so it is queryable as part of the epoch record. The ELSO Registry records such a catheter as a cannula entry with Initial Purpose "Distal reperfusion catheter (DPC)".
Arterial access anatomy — the TBox defines ecmo-co:AccessArtery (an artery used as the insertion vessel for a V-A return cannula), but this scenario does not use it: the femoral sites appear only in cannula labels.

SPARQL Competency Queries

Q1 — List all cannulae in the circuit, their role type, and whether a matching function is borne

# Namespace declarations omitted.
SELECT ?cannula ?roleType ?hasFunction
WHERE {
  ?circuit bfo:0000178 ?cannula .
  ?lc      bfo:0000176 ?cannula ;
           ecmo-co:bears   ?role .
  ?role    rdf:type    ?roleType .
  FILTER(?roleType IN (
    ecmo-co:DrainageRole, ecmo-co:ReturnRole))
  BIND(IF(?roleType = ecmo-co:DrainageRole,
    ecmo-co:DrainageFunction, ecmo-co:ReturnFunction) AS ?fnType)
  OPTIONAL {
    ?lc ecmo-co:bears ?fn .
    ?fn rdf:type  ?fnType .
    BIND(true AS ?hasFunction)
  }
}
ORDER BY ?cannula
?cannula | ?roleType | ?hasFunction --------------------|----------------------|------------- :Cannula_FemA_17Fr | ecmo-co:ReturnRole | true :Cannula_FemV_25Fr | ecmo-co:DrainageRole | true :DistalPerfCath_8Fr | ecmo-co:ReturnRole | (unbound)

The distal perfusion catheter's lumen conduit bears a ReturnRole with no matching ReturnFunction.
