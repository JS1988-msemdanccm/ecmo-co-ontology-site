Clinical Scenario

V-V ECMO — AVALON Elite Dual-Lumen, Single Right IJ Cannulation

Adult patient with severe ARDS requiring V-V ECMO. A single AVALON Elite 27 Fr dual-lumen cannula is placed via the right internal jugular vein. The distal tip resides in the IVC; the mid-cannula return opening directs oxygenated blood toward the tricuspid valve.

  • Drainage: two fenestrations — distal in IVC + proximal in SVC — via the outer drainage lumen
  • Return: one mid-cannula fenestration in right atrium, jet directed at tricuspid valve — via the inner return lumen
  • Single-site access: only one venous puncture site (right IJ)
  • Centrifugal pump + PMP hollow-fibre oxygenator
Key ECMO-CO Features in This Scenario
Two LumenConduits in one Cannula — the AVALON cannula hosts two coaxial LumenConduit (FiatObjectPart) individuals, each bearing its own Function and Role; ECMO-CO encodes this via bfo:0000176 (part-of) to the same Cannula individual
3 CannulaFenestrations — two drainage openings (IVC + SVC) bound to the drainage LumenConduit; one return opening (RA) bound to the return LumenConduit; each asserts ecmo-co:opensInto its CannulaLumen
ecmo-co:opensInto property — links each CannulaFenestration (BFO Site) to the CannulaLumen (BFO Site) it communicates with; the fenestration itself is part of (bfo:0000176) the LumenConduit, so the immaterial channel and the material wall stay distinct
Both DrainageRole and ReturnRole on one physical cannula — the ELSO Registry records a dual-lumen cannula as one cannula entry with Initial Purpose "Both drainage and return" and has no per-lumen or fenestration fields. ECMO-CO places each role on a distinct lumen-conduit part of the same cannula individual

SPARQL Competency Queries

Q1 — List all fenestrations and the lumen each opens into

# Namespace declarations omitted.
SELECT ?fen ?label ?lumen
WHERE {
  ?fen  rdf:type       ecmo-co:CannulaFenestration ;
        rdfs:label     ?label ;
        ecmo-co:opensInto  ?lumen .
}
ORDER BY ?fen
?fen | ?label | ?lumen ----------------------------|-----------------------------------------------------------------------|------------------------------ :CannulaFenestration_AV_IVC | "Distal drainage fenestration in IVC" | :CannulaLumen_AVALON_Drainage :CannulaFenestration_AV_RA | "Mid-cannula return fenestration in right atrium (jets to tricuspid)" | :CannulaLumen_AVALON_Return :CannulaFenestration_AV_SVC | "Proximal drainage fenestration in SVC" | :CannulaLumen_AVALON_Drainage

Q2 — Verify both DrainageRole and ReturnRole exist on one cannula's parts

# Namespace declarations omitted.
ASK {
  ?cannula  rdf:type    ecmo-co:Cannula .
  ?lc1      rdf:type    ecmo-co:LumenConduit ;
            bfo:0000176 ?cannula ;
            ecmo-co:bears   ?dr .
  ?dr       rdf:type    ecmo-co:DrainageRole .
  ?lc2      rdf:type    ecmo-co:LumenConduit ;
            bfo:0000176 ?cannula ;
            ecmo-co:bears   ?rr .
  ?rr       rdf:type    ecmo-co:ReturnRole .
  FILTER(?lc1 != ?lc2)
}
true

The AVALON cannula has a DrainageRole and a ReturnRole, each borne by a different lumen-conduit part.
